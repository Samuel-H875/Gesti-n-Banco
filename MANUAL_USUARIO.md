# Manual de usuario breve — NovaBank

## 1. Registrar un cliente

1. Seleccionar **Registro**.
2. Escribir nombre, documento, correo, teléfono y contraseña.
3. Enviar el formulario.
4. Si los datos son válidos, el sistema crea el cliente y una cuenta de ahorros inicial.
5. Ir al formulario de inicio de sesión.

## 2. Iniciar sesión como cliente

1. Escribir el correo registrado.
2. Escribir la contraseña.
3. Seleccionar la opción de ingreso.
4. El sistema mostrará el panel del cliente.

Desde el panel se pueden consultar los datos personales, las cuentas y el saldo total.

## 3. Realizar un depósito o retiro

1. Seleccionar la cuenta.
2. Introducir una cantidad positiva.
3. Elegir **depositar** o **retirar**.
4. Confirmar la operación.
5. Revisar el mensaje mostrado por el sistema.

Un retiro no se realiza si el saldo es insuficiente, la cantidad no es válida o la cuenta está desactivada.

## 4. Actualizar el perfil

1. Entrar al panel del cliente.
2. Cambiar el nombre o teléfono permitido.
3. Guardar los cambios.
4. Verificar el mensaje de confirmación.

## 5. Iniciar sesión como administrador

Usar las credenciales de demostración:

```text
Correo: admin@banco.com
Contraseña: Admin123*
```

En el panel administrativo se pueden consultar y gestionar clientes, cuentas, empleados y cargos.

## 6. Cerrar sesión

Seleccionar **Cerrar sesión**. La sesión actual se invalida y el sistema regresa a la página inicial.

## 7. Recomendaciones

- Utilizar datos de prueba, no información real.
- Comprobar los mensajes de error cuando se ingresen cantidades inválidas.
- No publicar las credenciales administrativas en un entorno real.
